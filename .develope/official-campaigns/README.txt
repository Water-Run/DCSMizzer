DCS Official Campaign Development References

This directory may contain local copies of official DCS World campaign files
for read-only development research. They are useful for studying established
mission structure, campaign progression, briefings, triggers, and scenario
design. They are not DCSMizzer source and are not part of the Agent-facing
Docs directory.

The ignored DCSWorld tree mirrors these locations in a local Steam installation:

* Mods/aircraft/JF-17/Missions/Campaigns
* Mods/aircraft/M-2000C/Missions/Campaigns
* Mods/aircraft/Su-25T/Missions/Campaigns
* Mods/campaigns/M2000C Red Flag

These campaign files remain the property of Eagle Dynamics and their
respective authors or publishers. Do not commit or redistribute them. The
parent repository tracks only this README.txt; all copied campaign content is
intentionally ignored.

Never edit the DCS World installation in place. To refresh these references,
copy them again from a legitimate local installation into the ignored
DCSWorld tree. Steam updates or file verification may replace files in the
installation directory.
