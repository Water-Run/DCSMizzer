# BriefingRoom situations index

**110** situation templates with red/blue control polygons.

Data: [`../data/briefing-room-situations-index.json`](../data/briefing-room-situations-index.json)

## Shape

```json
{
  "DisplayName": {"en": "..."},
  "Theater": "GermanyCW",
  "redZones": [[[x,y], ...]],
  "blueZones": [[[x,y], ...]],
  "noSpawnZones": []
}
```

Zone coordinates are map meters (`x` north, `y` east).
