== 快速任务

=== 飞行与程序

==== 自由飞行

===== 日间自由飞行

[source,text]
----
生成高加索 F-16C 日间自由飞行。玩家与 AI 僚机从沿海机场热启动，在晴朗轻风中飞约 30 分钟；加入少量民航和机场活动，但无敌军、强制航点或胜负条件，可随时返场、复飞或重开。

核实机场、交通和航路后，生成 .miz 与简报并验证间隔和恢复。
----

===== 夜间自由飞行

[source,text]
----
制作波斯湾全模拟 M-2000C 夜间自由飞行。玩家与友机从跑道起飞，在月光薄云下飞越城市与海岸约 35 分钟；一架中立客机保持安全间隔，无战斗或强制动作，可复飞或备降。

依据核实的机场、夜间天气和航线，生成并验证 .miz 与简报。
----

===== 地形观光

[source,text]
----
生成德国冷战地图 MiG-29G 观光任务，背景为统一后的德国空军交流飞行。玩家与僚机从西部机场热启动，在秋日下午散云中飞约 45 分钟，沿途观察友军运输机和民航；无敌军或胜负条件，可提前返场再起飞。

先查地图、机型和航点，再生成并验证 .miz 与路线简报。
----

===== 恶劣天气飞行

[source,text]
----
做一个科拉全模拟 MiG-29A 恶劣天气自由飞行。玩家与 AI 僚机黎明冷启动，在低云、降雪和强侧风中飞约 40 分钟；云上有友军运输机，基地保持活动，无战斗目标，可提前返场或备降。

天气、航路和出生状态须先核实，再生成并验证 .miz 与仪表简报。
----

==== 启动与起飞

===== 冷启动

[source,text]
----
在 Nevada 的 Nellis 基地生成 JF-17 冷启动练习。玩家夏季清晨从停机坪完成上电、航电准备、滑行和起飞，与友军 JF-17 会合后飞 20 分钟本场航线；保留少量地面和空中交通，可中止启动、复飞或重开。

用核实的停机位、滑行、无线电和航路生成并验证 .miz 与新手简报。
----

===== 热启动

[source,text]
----
给我一个 Marianas F-15C 热启动任务。玩家与 AI 僚机从陆上机场出发，在热带上午散云轻风中练习导航、队形转换并返场，约 35 分钟；高空有友军巡逻机，机场有运输机，可提前脱离或复飞。

生成 .miz 与简报前确认地图、出生点和 AI 航路，再验证。
----

===== 跑道起飞

[source,text]
----
制作高加索 Su-25T 跑道起飞练习。阴天上午，玩家按指定剖面爬升，飞过训练区航点并跟随友军教练机返场，约 25 分钟；运输机在玩家离场后起飞，可直接返场、复飞或备降。

用 Docs 和 Tools 核实跑道、出生与交通时序，生成并验证 .miz 与程序提示。
----

机场、进场和交通核实后，生成 .miz 与进场卡并验证间隔和复飞。

根据核实的设施、天气和进近数据制作并验证 .miz 与程序简报。
