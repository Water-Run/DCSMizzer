[[getting-started]]
== 先从这里开始

Prompt 没有规定长度。下面三种写法都有效：信息越少，最终程序需要自行补全的设计决定越多；信息越多，结果越接近你的具体设想。

=== 一句话

[source,text]
----
给我生成一个高加索 F-16C 双机拦截任务：冷启动，阴天，约 45 分钟，难度适中。
----

=== 标准描述

[source,text]
----
制作一个冷战德国地图的 MiG-21Bis 单人拦截任务。时间是 1970 年代秋季黄昏，玩家与一架 AI 僚机从东德机场警报起飞，拦截一支低空接近的攻击机编队。

任务约 50 分钟，难度适中，重点是地面引导、目视识别、一次主要交战和安全返航。加入少量符合年代的机场活动，并提供清晰任务简报。
----

=== 详细描述

[source,text]
----
我想要一个西奈地图的双人合作任务。两名玩家驾驶 JF-17，从后方机场冷启动，为随后进入的 M-2000C 打击编队压制一处中程防空阵地。

任务发生在夏季黎明，低空有薄雾，目标区附近有村镇和中立道路交通。敌方雷达会间歇关机，并有近程防空和诱饵阵地保护。玩家的目标是在约 20 分钟的打击窗口内让主要威胁无法有效射击，不要求摧毁所有单位。

总时长约 75 分钟，难度偏高，但不要依赖突然贴脸生成敌人。允许任务失败后继续返航。请提供分工明确的双人简报、无线电信息和成功/失败条件，并生成、检查可游玩的 `.miz`；如果某项要求确实无法实现，请明确说明，不要擅自替换机型或地图。
----

[[quick-training]]
== 快速训练

立刻、短时的练习与短战斗：自由飞行、冷启动、程序课，以及打完即结束的紧凑空战。

=== 自由飞行

==== 日间自由飞行

[source,text]
----
生成西奈 **TF-51D** 日间自由飞行。TF-51D 为**现代退役野马**教练/展示机（非二战现役）。晴朗轻风，玩家与 AI 僚机从经核实的西奈/苏伊士方向可用机场热启动，沿运河、海岸与**金字塔/开罗方向**（地图可视范围内）走**可落地的观光/VFR 航线**约 40 分钟——贴合真实走廊、海岸线与常用目视点，禁止随意折线刷点。

空域要「活」但别假、也别卡：军用运输/巡逻、直升机转场、轻型螺旋桨或教练本场、远处不交战战斗机训练等**多层多样化**；民航少量点缀。机型须**匹配当代/退役展示语境**（禁止错时代）。**性能与规模**：以稳定流畅和场景可读为先，使用足以营造氛围的克制规模。**出生与时间线（自由飞行）**：开局可以有少量交通已经在航路上；后续飞机优先从停机坪或滑行道延时启动、错峰起飞，避免在玩家眼前突然生成或开局全体同时离地。无强制航点、无敌军、无胜负；可随时返场、复飞或重开。

核实时代机型、机场、真实感航线、错峰时间线与单位总数后，生成 .miz 与简报并验证恢复路径。
----

==== 夜间自由飞行

[source,text]
----
制作德国冷战地图 **全模拟 MiG-29A** 夜间自由飞行。月光薄云，玩家与友机从东德机场跑道起飞，沿**冷战走廊/边界灯火向**可落地夜航线约 35–40 分钟（贴合常用航路与机场灯光，非随机折线）。

环境交通**多样化且克制**：运输机走廊、直升机场坪、远处友军夜航训练、地面滑行与灯光；民航少量。机型须**匹配冷战东德时间点**。**性能与规模**：以稳定流畅和场景可读为先。**出生与时间线**：开局可以有少量航路交通；后续飞机优先从地面延时启动并错峰起飞，避免在玩家眼前突然生成或全体同时离地。无战斗、无强制航点、无胜负；可复飞、备降或重开。

核实机场、夜间天气、时代机型、航线、错峰时间线与单位总数后生成并验证 .miz 与简报。
----

==== 地形观光

[source,text]
----

沿途**多样化**且克制：友军运输、直升机低空、靶场外缘不交战战斗机通场、公路/机场地面活动；民航点缀。机型须**匹配冷战东德时间点**。**性能与规模**：以稳定流畅和场景可读为先。**出生与时间线**：开局可以有少量航路交通；后续飞机优先从地面延时启动并错峰起飞，避免在玩家眼前突然生成。无敌军、无胜负；可提前返场再起飞。

核实地图、全模拟机型、航线、错峰时间线与单位总数后生成并验证 .miz 与路线简报。
----

==== 恶劣天气飞行

[source,text]
----
制作**科拉** **JF-17** 恶劣天气自由飞行（真正恶劣，非薄雾观光）。低云、吹雪/侧风、能见度受限；玩家与 AI 僚机从经核实机场冷/热启动，沿**可落地近海/峡湾 VFR 或低高度仪表过渡航线**约 35–40 分钟；可提前返场或备降。无战斗、无强制胜负。

交通**多样化、克制**：本场轻型/运输、直升机、远处不交战战斗机；民航少量。机型**当代北欧/训练语境**。**性能与规模**：以稳定流畅和场景可读为先。**出生与时间线**：开局可以有少量航路交通；后续飞机优先从地面延时启动并错峰起飞，避免在玩家眼前突然生成。

核实天气、航路、时代机型、错峰时间线与单位总数后生成并验证 .miz 与简报。

=== 程序

==== 启动与起飞

起降/程序类训练默认：**全模拟机型为主**（文中默认主座优先全模拟）；另提供**可选机型清单**（任务槽/F10/客户端可选，列 2–4 型已安装全模拟，必要时 1 型 FC/免费备选；未安装禁止入表）。须支持 **F10 连续练习与复活**（重置本课、玩家回停机坪/跑道头复活、僚机重置）。

===== 冷启动

[source,text]
----
在德国冷战地图前线机场生成冷启动练习。**默认主座全模拟 MiG-29A**；**可选机型清单**（须核实已安装）：全模拟 M-2000C、JF-17、F-16C 等。夏季清晨从停机坪完成上电、航电、滑行与起飞，与友军同型会合后飞约 20 分钟本场航线；少量交通。可中止启动、复飞；无敌军。

**训练循环（F10/复活）**：F10 至少：重置冷启动课、**玩家回停机位复活**、僚机重置、重新上电流程；可连续练启动，不强制一次起飞结束。

用核实的停机位、滑行、无线电、航路、机型清单与 F10 生成并验证 .miz 与新手简报。
----

[source,text]

**训练循环（F10/复活）**：F10 重置出航、玩家热启动复活、僚机重置；可连续本场课。

确认地图、出生、机型清单支持项、AI 航路与 F10 后生成并验证 .miz 与简报。

===== 跑道起飞

[source,text]
----
制作**高加索**跑道起飞/爬升剖面练习。默认免费 **Su-25T**（非全模拟座舱模块）；**可选清单**：全模拟 M-2000C、JF-17、A-10C II 等已安装对地/多用途全模拟。阴天上午按指定剖面爬升，训练区航点后跟教练机返场；运输机在玩家离场后起飞。可复飞或备降；无敌军。

**训练循环（F10/复活）**：F10 重置起飞课、玩家回跑道头/滑行道复活、教练机重置；可连续起降剖面。

核实跑道、出生、交通时序、机型清单与 F10，生成并验证 .miz 与程序提示。

==== 导航与着陆

着陆训练默认：**全模拟为主** + **可选机型清单** + **F10 连续进近/复活**（复飞、再进近、玩家回五边/长五边复活、重置风况可选）。

===== 目视着陆

[source,text]
----
生成日间目视着陆练习。高加索。**默认全模拟 F-16C**（视野适合目视航线）；**可选清单**：全模拟 M-2000C、JF-17、全模拟 MiG-29A、F/A-18C 等已安装全模拟。场外约 15 海里加入航线，跟同型教练机；少量友军起降，好天气轻风；全停、触地复飞、再进近或备降。

**训练循环（F10/复活）**：F10 至少：重置进近、**玩家回五边/15 nm 复活**、教练机重置、再来一次全停；可连续目视课，不强制一次落地结束。

核实机场、进场、机型清单、交通与 F10，生成 .miz 与进场卡并验证。
